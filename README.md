# AI/ML Engineer Personal Portfolio

A sleek, modern, and futuristic personal portfolio website designed for an AI/ML Engineer. Built with HTML, CSS, and Vanilla JavaScript, this portfolio features a premium dark UI with glassmorphism effects, neon glowing highlights, and smooth scroll animations.

## ✨ Features

- **Premium Dark Futuristic UI**: High-end aesthetic with neon glowing accents.
- **Glassmorphism Design**: Frosted glass effects on cards and forms.
- **Dynamic Typing Effect**: Animated hero text showcasing multiple roles.
- **Scroll Reveal Animations**: Smooth fade-in effects triggered by an Intersection Observer.
- **Responsive Layout**: Mobile-first design that adapts beautifully to any screen size.
- **Interactive Social Links**: Engaging hover animations with glowing drop-shadows.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and structure.
- **CSS3**: Modern styling with CSS variables, Grid, Flexbox, and complex animations.
- **JavaScript (Vanilla)**: DOM manipulation, smooth scrolling, and dynamic UI logic.
- **FontAwesome**: Vector icons for projects, tech stacks, and social links.
- **Google Fonts**: *Outfit* and *Space Grotesk* for a tech-oriented typographic feel.
